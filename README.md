# 냉장고 문 시퀀스: 새는 빛

냉장고 문이 닫혀 갈수록 틈으로 새는 빛이 좁아지고 격해지다가, 닫히는 순간 꺼지는 인터랙티브 영상 작업입니다. 문의 열림각 하나가 입력이고, 그 입력을 여덟 가지 시각 언어로 옮긴 화면과 칸마다 하나씩 깔린 노래가 함께 반응합니다.

파일 하나(`index.html`)로 돌아가며 외부 라이브러리를 쓰지 않습니다.

## 실행

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

`index.html`을 더블클릭해서 열어도 화면은 돌아가지만, `file://`로 열면 카메라와 `audio` 폴더 불러오기가 막힙니다. 카메라는 **https 또는 localhost**에서만 열립니다.

GitHub Pages로 공개하면 https 주소가 나오므로 폰에서도 카메라와 소리가 모두 됩니다 (Settings → Pages → Branch: `main` / root).

## 여덟 가지 화면

| 번호 | 타입 | 한 칸의 정체 | 닫힐 때 |
|---|---|---|---|
| 1 | A 흑백 물결 | 둥근 망점 | 점마다 브라운관처럼 눌려 꺼진다 |
| 2 | B 잉크 선 | 리소그래프 선 스크린 | 잉크가 빠지며 먹색 선으로 |
| 3 | C 열화상 | 네모 픽셀, 온도 눈금 | 식으며 1비트 냉장고로 |
| 4 | D 성운 | 가스와 별 | 별의 회절선이 접힌다 |
| 5 | E 필름 | 감광된 은입자 | 타고 음화로 뒤집힌다 |
| 6 | F 픽셀 소팅 | 흘러내리는 화소 기둥 | 흐름이 멈춘 잿빛 사진 |
| 7 | G 액체 크롬 | 녹은 금속의 높이 | 굳은 무채색 부조 |
| 8 | H 서툰 모델링 | 블렌더 뷰포트의 로우폴리 메시 | 빛 메시가 접히고 Solid 모드로 |

그리드(3×3)에서는 여덟 화면과 센서 계기가 한꺼번에 보이고, 칸을 누르면 그 화면으로 들어갑니다. 왼쪽 위 **← 전체 보기**(또는 Esc)로 돌아옵니다.

## 조작

| 키 | 동작 |
|---|---|
| ← → | 문 각도 (Shift로 크게) |
| Space | 자동 여닫기 |
| 1–8 | 타입 |
| G | 3×3 그리드 |
| Esc | 전체 보기로 |
| M | 소리 켜고 끄기 |
| Q | 화질 (자동 / 선명 / 가볍게) |
| V | 냉장고 / 추상 화면 |
| H | 패널 숨기기 (화면 두 번 탭도 됨) |

화면을 좌우로 끌어도 문이 움직입니다.

## 센서 (카메라 밝기로 여닫힘 판정)

패널의 **센서**를 누르면 카메라가 문틈의 밝기를 읽어 문 각도를 움직입니다. 설치 현장에서 문을 닫고 **닫힘 보정**, 활짝 열고 **열림 보정**을 한 번씩 누르면 그 사이가 0°–110°로 맞춰집니다.

가장 피해야 할 오판은 "실제로 닫혔는데 열림으로 읽는 것"이라, 판정은 언제나 닫힘 쪽으로 기울어 있습니다. 열림은 0.18초 연속으로 넘어야 인정하고 닫힘은 0.05초면 받아들이며, 문턱을 두 개(히스테리시스) 두고, 오래 열림이면 감시 타이머가 기준을 다시 잡습니다.

## 소리

칸마다 노래 하나. 그리드에서는 아홉 곡이 섞이고(줄마다 왼쪽·가운데·오른쪽), 한 칸으로 들어가면 그 칸의 곡만 남습니다.

재생속도는 열림각을 따릅니다. 테이프처럼 음정도 함께 움직입니다.

| 열림각 | 속도 |
|---|---|
| 110° (최대로 활짝) | 0.70× |
| 90° (냉장고 옆면과 일직선) | 1.00× |
| 닫히기 직전 | 1.80× |
| 닫힘 | 곧바로 0.20× |

바꾸려면 `index.html`에서 `DEG_FLAT = 90, RATE_WIDE = 0.7, RATE_EDGE = 1.8, RATE_SHUT = 0.2` 한 줄을 고치면 됩니다.

### 노래 넣기

`audio/1.mp3` … `audio/9.mp3`를 바꿔 넣으면 됩니다(.m4a .wav .ogg도 됨). 지금 들어 있는 곡은 칸마다 컨셉에 맞춰 합성한 시험용 루프입니다. `audio` 폴더가 비어 있으면 페이지가 같은 곡을 즉석에서 합성해 채웁니다.

| 번호 | 칸 | 번호 | 칸 |
|---|---|---|---|
| 1 | A 흑백 물결 | 6 | F 픽셀 소팅 |
| 2 | B 잉크 선 | 7 | G 액체 크롬 |
| 3 | C 열화상 | 8 | H 서툰 모델링 |
| 4 | D 성운 | 9 | 센서 칸 |
| 5 | E 필름 | | |

파일을 칸 위에 끌어다 놓거나 **노래 넣기**로 바로 시험할 수도 있습니다. 이름이 `3.mp3`, `C_heat.wav`처럼 숫자나 A–H로 시작하면 그 칸으로 들어갑니다.

### 루프 만들기

- **길이**: 20–45초, 마디에 딱 맞게. 길이(초) = 마디 수 × 한 마디 박 수 × 60 ÷ BPM (예: 120 BPM 4/4 16마디 = 32초)
- **자르기**: 박자 격자에 붙여 첫 박 정박에서 시작해 다음 첫 박 바로 앞에서 끝냅니다
- **잔향 꼬리**: 루프 끝 뒤로 흘러나가는 리버브를 잘라 루프 맨 앞에 겹쳐 섞습니다 (매끄러운 루프의 핵심)
- **페이드 없음**. 딸깍 소리가 나면 자르는 지점을 영점 교차로
- **음량**: 아홉 곡을 -16 LUFS, 피크 -1 dBTP 정도로 맞춥니다
- **형식**: 가장 확실한 건 WAV. MP3·M4A는 일반 인코더(LAME, Audacity, ffmpeg)로 내보내면 헤더의 무음 정보를 브라우저가 읽어 정확히 이어 붙입니다

브라우저는 사용자가 한 번 눌러야 소리를 냅니다. 전시에서는 시작할 때 **소리** 버튼을 한 번 눌러 두세요.

## 구조

모든 것이 `index.html` 한 파일 안에 있습니다.

- **공통 엔진**: 냉장고의 3D 투영, 틈의 각도, 바닥의 빛 쐐기, 허공의 광선, 번지는 빛, 칸 단위 꺼짐, 빛의 부피와 먼지
- **타입별 그리기**: `drawA` … `drawG`, `renderBlender`
- **적응형 화질**: 프레임 시간을 재서 그리는 해상도를 자동으로 조절하고, 쉬는 화면은 다시 그리지 않습니다
- **소리**: Web Audio. `TESTLOOP`(시험용 루프 합성기), `AUD`(재생·섞기·속도)
- **센서**: `SENSOR`
